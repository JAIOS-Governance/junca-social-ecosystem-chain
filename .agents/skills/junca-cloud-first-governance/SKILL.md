# JUNCA / JAIOS Cloud-First Governance

1. Read the Creative Constitution and `docs/CODEX_PC_COMPLETE_INDEPENDENCE_POLICY.md` before implementation and before material architecture decisions.
2. Treat every personal computer, local IDE, GitHub Desktop installation, local clone, local scheduler, localhost service, self-hosted runner, and local secret store as optional only.
3. Preserve an executable route through Codex Cloud, connected GitHub repositories, GitHub-hosted Actions, approved cloud runtimes, Google Drive, connectors, and API readback.
4. Never return connector-capable setup, file operations, commands, monitoring, validation, or recovery to the CEO.
5. Ask the CEO only for platform-enforced identity verification, MFA, legally binding approval, payment approval, or a material business decision that cannot be delegated.
6. Require a feature branch, independent review, CI, exact SHA, rollback, and machine-readable evidence before completion.
7. If a local dependency is detected, return the affected scope to Repair & Remediation and replace the route before activation.
