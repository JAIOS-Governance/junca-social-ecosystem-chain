## Release boundary

All public communication must distinguish verified state from direction.

- Brand and governance information: public
- Technical documentation: public
- Public Testnet runtime: pending verification unless current evidence states otherwise
- Mainnet: not released
- Bridge: paused / not activated
- Monetary-value or investment claims: prohibited without separate verified legal and release approval

## Distribution model

1. **Search integrity** — canonical URLs, structured data, sitemap, robots policy, Search Console evidence, and backlink consistency.
2. **Message integrity** — one current naming system, one institutional operator, explicit release boundaries, and bilingual parity.
3. **Channel integrity** — channel-specific copy derived from the same canonical facts, never copied from old posts without readback.
4. **Evidence integrity** — each public status statement must be traceable to the brand site, technical reference, repository evidence, or current Drive canon.
5. **Change integrity** — changes to name, status, operator, URLs, or release state require synchronized updates across this directory, public metadata, official profiles, and the Drive ChangeLog.
